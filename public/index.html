Is My Block Final Yet?

An explorer saying "success" means your transaction was included — not that it is final. Confirmed ≠ final: until the finalized head passes your block, a reorg can still undo it. Paste a block number or a transaction hash and ChainLens checks it against the live finalized head.

Stop counting blocks

Confirmation counts are folklore — the number that was safe last year says nothing about today. Ask for the finalized block instead; it is the chain's own answer.

// ethers v6
const fin = await provider.getBlock('finalized');
const isFinal = myBlock <= fin.number;
// viem
const fin = await client.getBlock({ blockTag: 'finalized' })
const isFinal = myBlock <= fin.number

Bridge Wait Estimator

Bridging has two waits: the source chain finalizing (measured live by ChainLens) and the bridge protocol's own rules (labelled CONSTANT — protocol parameters, not measurements). They are shown separately, never merged into a fake single number. Expectations only — ChainLens cannot track or recover a transfer.

Waiting for finalized-block events…

Portaldot finality comes from GRANDPA: validators vote on blocks and a block is finalized once a supermajority agrees — typically about two blocks behind the head here, which is why Portaldot settles in seconds while chains that wait for checkpoint epochs take minutes. ChainLens reads both the EVM and the native Substrate view of that same GRANDPA finality and shows you when they disagree.

Verify It Yourself

Don't trust the dashboard — check it. Each button takes one fresh sample straight from that chain's public RPC and shows the raw values next to the numbers ChainLens computed from them. Finality lag is simply latest − finalized; finality time is lag × measured block time.

      finality — the L2's view of L1 finality — which is exactly the wait bridges and exchanges
      experience. Bor chains (Amoy, Polygon) report finality as n/a by design. The Finality Index
      is a log scale: 5s = 100, 30 min = 0, computed from the session average. Bridge waits marked
